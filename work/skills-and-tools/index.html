我大约在 2016 年开始从事 Web 开发，接触过前端与后端的多种编程语言和技术栈。

虽然 Web 开发的范围很广，我最感兴趣并专注于前端开发与 UI/UX 设计。

前端开发

我喜欢创造简洁、极简、具有吸引力和价值，而且易于使用的产品。

我尤其喜欢制作包含丰富 UI 组件的 Web 应用、文档页面、CMS 内容布局与仪表板布局，也喜欢简单的落地页。

TypeScript

我习惯使用 TypeScript。这个 JavaScript 超集从 2018 年起一直伴随着我的开发工作。

React

我很喜欢构建单页应用，React 是我的首选库。从 2018 年开始使用至今，我已积累了丰富经验。

Vue.js

Vue.js 是我用于单页网站的另一个得力工具，也是在工作中逐渐熟悉的技术。

Tailwind CSS

我很喜欢使用 Tailwind CSS 编写样式，尽管使用 SCSS 的时间更久。

Framer Motion

对于动画，我更习惯使用 Framer Motion。它让 JavaScript 动画的创建变得轻松。

Next.js

发现 Next.js 之后，它就成为我最喜欢的 Web 框架之一。

UI/UX 设计

我从 2018 年起持续进行 UI/UX 设计。除了创建视觉上吸引人的界面，我也会持续思考如何为用户提供更好的体验。

最大的挑战，是在出色的界面与优质的体验之间找到平衡。
