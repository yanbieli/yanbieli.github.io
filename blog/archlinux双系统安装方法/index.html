注：如果你有多块硬盘，并且打算用一整块硬盘安装archlinux，那么完全不用理会下面的内容，制作好启动U盘后，进入安装页面，连接好网络输入：

archinstall
TEXT 行数：1 UTF-8

就可以进行各种各样的配置，然后一键安装。只有一块硬盘，这个安装脚本会格式化整块硬盘，目前我没找到比较好的解决办法，下面的内容适合于在一块硬盘上安装Windows+archlinux双系统，其他的Linux系统也不用如此费事，都有图形化安装界面，可以自由选择安装位置，不用担心格式化掉整个硬盘。

默认UEFI启动。

一切皆文件

1.下载archlinux镜像文件

官网下载较慢，可以从对镜国家镜像源下载。

2.制作启动U盘

可通过rufus进行制作。

3.安装archlinux

3.1划分一块磁盘空间

在Windows系统内，通过磁盘管理工具划分出一块空闲空间，可以先不用新建和格式化，这里以128GB为例。

按键盘快捷键选择U盘启动，进入archlinux安装界面。

3.2联网

有线、无线连接皆可。

如果连接无线，WiFi名称里如果包含汉字会显示乱码。

筛选WiFi:iwlist wlan0 | grep ESSID，| 管道注入，grep相当于Windows里的搜索。

清屏：ctrl + L或输入clear。

如果iwctl显示不可用，可以用archinstall脚本拉取WiFi连接，然后Ctrl+Q退出即可。

这里选择通过USB共享热点。

3.3同步系统时间 

timedatectl set-ntp true
TEXT 行数：1 UTF-8

3.4分区

对提前划分好的磁盘空间进行分区，由于是安装双系统，archlinux可以和Windows共用EFI分区，可以省去划分这一个，只需分一个主分区和swap虚拟内存分区。

swap存放休眠文件或者当主机内存用满时作为扩展，不用很大。

网上一些教程说，如果需要用到休眠功能，swap>=内存，休眠是内核需要把整个内存写入swap，所以大于等于内存大小才能完整保存。具体大小参考官方文档和你的配置而定，自行斟酌。

列出硬盘文件，包含硬盘名字和分区

fdisk -l
TEXT 行数：1 UTF-8

我们划分出的那块空间不会在这里显示

通过

cfdisk /dev/nvmw0n1
TEXT 行数：1 UTF-8

对硬盘进行分区

这时我们划分的磁盘空间就显示出来了，前面会有绿色字体free标识。

上下键选中该free分区，左右键选择new，enter，会让你输入要划分多少空间。

这里以128GB为例，我swap准备分16GB，剩余全部划分为主分区。

先创建主分区，输入112G，enter，左右键选择write。

继续创建swap分区，输入16G，enter，左右键选择write。

单硬盘完整安装Linux但系统，需创建EFI分区，500MB左右。

fdisk -l
TEXT 行数：1 UTF-8

就可以看到我们的完整分区。

制作EFI分区：mkfs.fat -F32 /dev/EFI分区名称。

制作主分区

mkfs.ext4 /dev/nvme0n1p6
TEXT 行数：1 UTF-8

看有无报错，报错了看输入命令是否正确。

制作swap分区

mkswap /dev/nvme0n1p7
TEXT 行数：1 UTF-8

打开swap

swapon /dev/nvme0n1p7
TEXT 行数：1 UTF-8

3.5配置软件源

配置pacman配置文件

vim /etc/pacman.conf
TEXT 行数：1 UTF-8

color的注释删掉，安装过程会给你彩色的提示，这个文件里包含一些软件源文件位置mirrorlist。

vim /etc/pacman.d/mirrorlist
TEXT 行数：1 UTF-8

将中国源整个剪切粘贴至开头。

将光标移动到china，按v，按下方向键选中china所有源按d，移动光标到开头，按p。

3.6正式安装

将arch放进对应分区。

挂载系统盘，现在到目前为止都是在U盘里操作。

我们想把系统主要内容安装在主分区，系统引导安装之EFI分区内。

系统自动提供的文件夹/mnt

把主分区挂载到/mnt

mount /dev/nvme0n1p6 /mnt
TEXT 行数：1 UTF-8

看/mnt里有什么

ls /mnt
TEXT 行数：1 UTF-8

输出：lost + found

创建一个文件夹

mkdir /mnt/boot
TEXT 行数：1 UTF-8

挂载引导分区

mount /dev/nvme0n1p1 /mnt/boot
TEXT 行数：1 UTF-8

开始安装

pacstrap /mnt base linux linux-firmware
TEXT 行数：1 UTF-8

生成fstab文件，可以让下次从archlinux启动时自动挂载这几个分区。

genfstab -U /mnt >> /mnt/etc/fstab
TEXT 行数：1 UTF-8

现在只是安装了archlinux很基本的东西，还没有桌面等等。
